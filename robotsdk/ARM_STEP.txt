单轴 / 单条机械臂 7 轴角度调整 V3（不做碰撞检测、不标定零位）

必须在机器人宿主机终端执行 arm-step.sh；不能同时运行 ROS SDK 驱动或其他关节控制程序。
只控制 --arm 指定的整组机械臂，不会使能腰腿、头颈、另一条臂。
单轴运动时其余关节保持当前位置，但被选中的整条臂都需要使能。

新增整臂预览（7 个数是绝对角度，单位度；目标只是示例，不保证适合当前姿态）：
/home/nvidia/robotsdk/arm-step.sh --arm left --targets-deg 90 -90 0 0 -90 0 0 --speed-percent 5
确认全路径及下使能支撑安全后执行：
/home/nvidia/robotsdk/arm-step.sh --arm left --targets-deg 90 -90 0 0 -90 0 0 --speed-percent 5 --execute
右臂把 --arm left 改为 --arm right；只使能所选一条臂，不同时操作双臂。
按 SDK 轴号 1～7 顺序：shoulder_yaw、shoulder_pitch、upperarm_roll、elbow_pitch、forearm_roll、wrist_pitch、wrist_yaw。
--targets-deg 必须正好 7 个数字，空格分隔，不加逗号；不能同时传 --joint 或单轴角度参数。
内部按实时 SDK joint_names 构建一个含 7 轴的目标字典，一次调用 move_joints，不是逐轴执行。
等待全部 7 轴到位且停稳后自动停止、下使能；任一轴超限时不使能、不运动。
一次下发不代表末端直线运动，也不承诺各轴精确同时到达；轨迹由 SDK/驱动规划。
不带 --execute 仍只打印运动前和目标两行角度；原有单轴、头颈、腰腿用法不变。

预览：只输出“运动前（度）”和“运动后目标（度）”两行7轴角度，不使能、不运动：
/home/nvidia/robotsdk/arm-step.sh --arm left --joint 4 --target-deg 0

执行（直接使能并运动，无 MOVE/DISABLE/STOP 输入环节，结束自动停止、下使能并退出）：
/home/nvidia/robotsdk/arm-step.sh --arm left --joint 4 --target-deg 0 --speed-percent 5 --execute
执行前须考虑结束时下使能的支撑安全。其他轴保持当前位置，但机械臂各段仍会随该轴转动。
异常退出/Ctrl+C 也会尝试停止并下使能；若失败会报错，不能当作已安全停止。

角度三选一：
--delta-deg 1     相对当前位置增加1度；负数为减小。
--target-deg 0    绝对到0度；仅受该轴真实硬件限位约束，无额外5度上限。
--toward-deg 0   朝0度靠近，默认每次最多1度；配合 --step-deg。
--joint 1..7 对应 SDK 关节顺序；--arm left/right。

速度：--speed-percent 1 -> SDK velocity_scale=0.01，即1%的SDK速度比例。
--speed-percent 2 -> 0.02；--speed-percent 5 -> 0.05（默认）；--speed-percent 10 -> 0.10。
不是每秒1/2/5度，也不是走1/2/5秒，不能据此保证固定实际速度。
实际速度取决于固件、低速模式、路径和加减速规划。
--accel-percent 1 -> acceleration_scale=0.01；默认1%，一般先保持不改。
速度/加速度比例范围为0.1%～100%，取消人为5%上限，但100%并非推荐值。
大幅运动前须确认全路径及机器人自身均无碰撞；限位检查不是碰撞检查。
--timeout 默认120秒；超过时停止并下使能；可调整到最多1800秒。

停止：Ctrl+C 请求停止并自动下使能（Python处理可能有延迟），紧急情况使用实体急停。
运动后程序自动停止、下使能、断开并退出，不再等待输入。
不要直接关闭终端来停运动；不要强制杀进程或停容器。
不带 --execute 的预览不会下发使能/运动指令；预览中“运动后”是目标，并非实际运动结果。

验证边界：V3 做语法、规划、模拟 SDK 生命周期及离线 Python 绑定测试；未执行真实整臂运动。
即使目标角度为0/90/-90，也不保证手臂垂直或无自碰撞，须小步观察确认。
